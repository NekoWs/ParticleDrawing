# 项目概览

ParticleDrawing 是一个为 NeoForge 编写的高性能粒子效果库，目标是在保证流畅度的前提下，提供一套简单、可组合、可扩展的服务端粒子 API。

## 核心定位

- **服务端权威**：粒子的真实状态只存在于服务端，客户端仅负责渲染与插值。所有逻辑（生成、销毁、变换、生命周期）都在服务端计算，保证多玩家一致。
- **高性能**：服务端按维度管理粒子，使用并发集合；客户端通过桥接原版粒子系统渲染，支持上万粒子同屏（详见内置的压力测试命令）。
- **可扩展**：通过运动算法（`MotionAlgorithm`）与缓动曲线（`EasingCurve`）可以自由扩展动画效果。

## 特性一览

- **单粒子控制**：`ParticleManager.create()` 构建器 + `ParticleHandle` 句柄，支持生成、移动、重着色、缩放、销毁。
- **粒子组（Group）**：`ParticleGroup` 可对整组粒子做平移 / 旋转 / 重着色 / 缩放，支持链式调用。
- **内置绘图 API**：`Draw` 提供线段、圆、圆盘、参数曲线、球体、三角形、六芒星、长方体、矩形等形状。
- **缓动系统**：14 种预设缓动 + 自定义三次贝塞尔曲线，支持网络序列化。
- **帧级运动算法**：在客户端每帧计算粒子位置/颜色/缩放，不受服务端 tick 频率影响；内置旋转、螺旋、涡旋、跟随玩家、距离缩放、渐变着色等算法。
- **动态光照**：发光粒子可照亮周围方块与实体。
- **命令演示**：`/particledraw` 提供一系列演示命令，快速验证 API 能力。
- **配置系统**：服务端 / 客户端分离配置。

## 逻辑分区

代码按职责分为以下几大块，详见 [架构与数据流](./architecture.md)：

| 包 | 职责 |
| --- | --- |
| `api` | 对外公开的 API（`ParticleManager`、`Draw`、`ParticleGroup` 等） |
| `core.server` | 服务端权威引擎与状态 |
| `core.client` | 客户端渲染、插值与桥接 |
| `core.network` | 网络数据包与编解码 |
| `core.easing` | 缓动曲线 |
| `core.motion` | 帧级运动算法系统 |
| `lighting` | 动态光照 |
| `command` | 命令与演示 |
| `config` | 配置定义 |
| `util` | 工具类 |
| `mixin` | 渲染光照注入 Mixin |
