# 粒子能力缺口盘点

对照常见粒子系统逐项核对现有实现，记录**确实做不到**和**只能勉强近似**的能力。
每一条都注明证据位置，避免下次重新判断一遍。

## 已经具备

| 能力 | 说明 |
| --- | --- |
| 形状与分布 | 点、曲线、空间网格、图片点阵；`where` 可做条件曲面 |
| 逐刻公式 | 位置/速度/加速度/颜色/尺寸/全亮/照明等级可写，支持噪声、矩阵、向量、条件 |
| 每颗粒子状态 | `state` 声明、`let` 中间量、`kill` 条件 |
| 光照 | 点光与射灯（锥角/朝向/软硬边/衰减/颜色），写入光图并染顶点色 |
| 贴图与精灵 | 贴图引用、UV 子矩形、逐帧 UV 更新、图片颜色采样 |
| 朝向 | 广告牌开关、三轴自转、`alignTo(from,to)` 固定朝向 |
| 缓动 | 位置/尺寸/颜色/光强的运行时缓动与寿命曲线 |
| 碰撞 | `collide solid\|liquid` + `bounce` + `friction`，沿世界坐标线段查询实际方块或液体形状 |
| 子发射 | `subemit count/lifetime/speed/scale`，粒子死亡时在原地爆发，只做一层防指数爆炸 |
| 软粒子（CPU 近似） | `soft <半径>`：按粒子中心沿六轴到方块表面的距离调整整颗透明度 |
| 速度拉丝 | `align_velocity` + `stretch`，长轴对齐速度并按速度拉长 |
| 丝带拖尾 | `trail <0..32>`：按刻记录世界轨迹，生成逐段渐隐、渐细的面向镜头丝带 |
| 距离 LOD | `particleLodDistance` 启用稳定距离抽样和远距剔除 |
| 动画 | `.pdrawc` 播放、形变编队、字幕、音频、相机 |

## 做不到

| 缺口 | 现状 | 证据 |
| --- | --- | --- |
| **公式读世界** | 公式是纯数学，拿不到方块、实体、光照信息。碰撞是本轮唯一的例外，走的是专用通道而不是公式 | `RecipeExpressions` 的输入表仅含 `u/i/t/age/x/y/z/vx/...` |
| **阴影与遮挡** | 动态光会穿墙，粒子也不投影（已知限制） | `doc/known-issues.md` |
| **十万级以上粒子** | 逐颗 CPU 更新 + 逐颗顶点写入，规模受单发射器 8192 与渲染上限 50000 限制 | `MAX_SEEDS = 8192`、`maxRenderParticles` 默认 50000 |

## 只能近似

| 能力 | 现在怎么做 | 差在哪 |
| --- | --- | --- |
| **重力/风场** | 用 `motion ay -0.02` 之类的公式自己写 | 没有共享的力场对象，多个发射器要各写一遍；也没有空间变化的湍流场 |
| **吸引/排斥** | 用公式按位置算径向速度 | 拿不到实体或目标点坐标，只能围着固定点做 |
| **闪烁/脉动** | 光强曲线或脚本逐帧改 | 没有内置噪声调制，想做不规则闪烁要自己写公式 |

## 后续可扩展

GPU 深度纹理软粒子可逐像素处理半透明粒子和地形的交界。当前的 CPU 软化已覆盖贴近方块的整颗淡出。
