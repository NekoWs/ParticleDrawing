# PD 粒子能力速览

## 现在能做到

- **发射和动画。** 用命令或 API 从曲线、网格、图片、文字和 OBJ 表面发射粒子，也能沿路径等距发射。编辑器可导出 `.pdrawc` 时间轴动画，包含拉丝、贴地淡出和拖尾。
- **世界交互。** 配方可用公式控制粒子，探测方块、液体和实体，按环境、邻居和力场改变运动。粒子可以碰撞反弹，也能在出生、接触或死亡时生成子粒子。
- **外观和光照。** 支持动画贴图、透明与加色混合、速度拉丝、丝带与管状拖尾、网格粒子和跨棱角印记。命令和 API 支持按场景深度淡出、折射场景，以及让点光和射灯受方块遮挡。
- **联机和距离分级。** 普通配方在客户端模拟并逐帧插值。可选的服务端同步能让晚加入的玩家接上当前粒子、子粒子和尾迹。远处可减少绘制，或回收普通持续配方的模拟状态。

## 现在还做不到

| 缺少的能力 | 为什么需要 |
| --- | --- |
| `.pdrawc` 世界交互和定位回放 | 让编辑器做好的雨滴能撞上游戏里的台阶并飞溅，跳转播放时也能还原碰撞和尾迹状态。 |
| `.pdrawc` 场景材质和网格外观 | 让逐像素淡出、热浪折射和网格碎片能随编辑器作品一起导出。 |
| 保留历史的模拟 LOD | 让远处的特效少占 CPU，玩家回来时还能接上已有粒子和尾迹。 |
| 实例绘制 | 让大量同类粒子复用一份网格，减少 CPU 逐颗提交顶点的开销。 |
| GPU 模拟 | 让风雪、星云等高密度效果把逐粒子的公式和运动交给 GPU，减轻客户端 CPU 负担。 |
| 原生模型姿势采样（暂缓） | 让火花沿正在挥动的剑刃飞出，或随实体的骨骼动作从模型表面发射。 |
| 独立控制拖尾 | 让弹道粒子消失后尾迹还能继续淡出，并能沿长度设置颜色和粗细。 |
| 跨服务器重启续播 | 让持续运行的特效在服务器维护后接着播放，保留已有粒子和尾迹。 |
