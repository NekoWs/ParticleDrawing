# PD 粒子能力速览

## 现在能做到

- **发射和动画。** 用命令或 API 从曲线、网格、图片、文字和 OBJ 表面发射粒子，也能沿路径等距发射。同一个生成器可以用发射窗口分段（先开场、后持续、到点停止），不需要外部计时器。编辑器可导出 `.pdrawc` 时间轴动画，包含拉丝、贴地淡出和拖尾。
- **世界交互。** 配方可用公式控制粒子，探测方块、液体和实体，按环境、邻居和力场改变运动。粒子可以碰撞反弹，也能在出生、接触或死亡时生成子粒子。
- **外观和光照。** 支持动画贴图、速度拉丝、丝带与管状拖尾、网格粒子和跨棱角印记。拖尾可沿长度渐变颜色和宽度，并在头部消失后独立淡出。命令和 API 支持场景深度淡出、折射，以及让点光和射灯受方块遮挡。
- **联机和距离分级。** 普通配方在客户端模拟并逐帧插值。服务端同步可给晚加入的玩家补发粒子、子粒子和尾迹。`simulation_range … preserve` 在远处暂停配方，回来后从原有年龄和尾迹续播。
- **批量实例绘制。** CPU 配方可复用相邻两刻的实例数据并由 GPU 插值，支持按深度排序的半透明粒子和共用 OBJ 网格。`burst_gpu` 由 GPU 推进固定锚点的一次性匀加速弹道。

## 现在还做不到

| 缺少的能力 | 为什么需要 |
| --- | --- |
| `.pdrawc` 场景材质、网格和独立拖尾 | 让热浪折射、网格碎片和独立渐隐的彩色尾迹能随编辑器作品一起导出。 |
| `.pdrawc` 世界交互和定位回放 | 让编辑器做好的雨滴能撞上游戏里的台阶并飞溅，跳转播放时也能还原碰撞和尾迹状态。 |
| GPU 持续发射 | 让风雪、落叶等长时间特效持续产生粒子，并由 GPU 更新和回收。 |
| GPU 逐刻公式和世界碰撞 | 让大批粒子在 GPU 上改变运动，并对地形和实体作出反应。 |
| 远处低频模拟 | 让远处的特效以较少的计算继续推进，回来时看到当前状态和已有尾迹。 |
| 跨服务器重启续播 | 让持续运行的特效在服务器维护后接着播放，保留已有粒子和尾迹。 |
| 原生模型姿势采样（暂缓） | 让火花沿正在挥动的剑刃飞出，或随实体的骨骼动作从模型表面发射。 |
