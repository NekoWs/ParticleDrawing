# 已知限制

## Minecraft 1.21.1

- 1.21.1 的数据包格式为 48，资源包格式为 34；在 1.21.1 使用 26.x 编写的命令函数时需换成该版本的 `pack.mcmeta`。

## 加色粒子的渲染管线

26.3 的粒子支持 OIT（顺序无关透明），加色粒子会走单独的三个阶段；26.2 没有这套设施，
加色仍用普通加色混合。两种做法在预览里结果一致，但 26.3 在密集叠加时不会有排序瑕疵。
两个平台的实现分别在 `platforms/neoforge-26.<版本>/` 下，共享测试只钉住对外行为
（半透明标记、贴图、加色层参与排序），具体管线各版本自管。
## 只做完整性校验的签名

`.pdrawc` 的公钥随文件一起内嵌，播放前的“验签”只能发现传输损坏和随手改动，不能证明来源：
任何人都能生成自己的密钥对重新签名。涉及不可信文件/服务器的解析路径都另有独立的计数、长度与
索引上限，不依赖签名做安全边界。

## 动画时间轴

- 循环动画的播放周期至少为 100ms。播放头每游戏刻推进 50ms，周期若能整除 50ms，取余后播放头会始终回到起点。
- 函数对象每帧最多补跑 64 次脚本 `tick`。大幅跳转或极高倍速会跳过其余脚本调用，粒子寿命仍按完整经过时间推进。

## 动态光照

地形按网格的顶点采样光照、色调和可选的方块阴影，较窄的锥光和阴影边缘受网格分辨率限制。
装了 Sodium 时地形网格由它生成，动态光改为并进它的方块光采样再走它自己的平滑光照与环境遮蔽，
地面光斑的亮度和颜色与不装时基本一致。方块的自发光面（emissive）和流体不参与这一路，
地形染色按方块中心采样，光斑边缘比不装 Sodium 时略粗。
可选光束沿轴线在首次碰撞处收短。采用独立光照模型的光影包可通过
[动态光源快照](lighting.md#客户端配置与光影)读取光源。

## 音频声像

编辑器使用 Web Audio 的等功率声像。播放端用 OpenAL，立体声平衡需要 `AL_SOFT_source_panning`。
缺少扩展时，立体声会退回原有播放路径，声像调节可能听不出变化。

使用扩展时，中间声像的线性增益和对侧声道混合方式与编辑器不同，正中与最左、最右的结果一致。
单声道用 OpenAL 的位置声像。

## 光影包

模组不覆盖任何原版着色器文件，自建的 `particle_instances`、`scene_particle` 两个程序放在自己的命名空间下，
光影包不会和它们抢文件。装了 Iris 并且正在使用光影包时，带自建管线的粒子会自动退回原版管线
（`[compatibility]` 的 `shaderCompat`，默认开）：加法粒子改用原版半透明管线，实例化与 GPU 配方降级成普通粒子，
`depth_fade` 与 `distortion` 按普通四边形绘制。这样光影包下不会出现「粒子整批不显示」，
代价是加法混合、实例化批次与场景材质效果变弱。光影包关掉后自建管线立刻恢复。

有些光影包忽略原版光图，地面可能看不到粒子灯的照明。启用 `shaderLightPools`（默认关）后，
兼容模式会在光源照到的表面绘制软光斑。如果光斑和地形动态光同时可见，可以关闭 `terrainDynamicLights`。

| 现象 | 原因 | 开关 |
| --- | --- | --- |
| 加法粒子过亮、遮挡或排序不对 | 加法粒子复用原版 `core/particle` 程序，光影包替换它后，混合函数按直通 alpha 写的前提可能不成立 | `customAdditivePipeline` |
| 逐像素淡出、折射的画面发灰或位置不对 | 这两项读本帧的颜色和深度副本，光影包可能更换渲染目标或改后处理顺序 | `sceneMaterials` |
| 地面被粒子灯照得过曝 | 动态光会烘进地形顶点（Sodium 下并进它的方块光采样），光影包自己计算地形光照时容易叠加 | `terrainDynamicLights` |
| 地面看不到粒子灯照明 | 光影包忽略原版光图 | 开启 `shaderLightPools`（默认关），并保留 `shaderCompat`（默认开） |

`[debug]` 段的 `forceLegacyPipelines` 能在没有光影包时预览上面这套降级效果。
排查顺序：先关 `terrainDynamicLights`（地面过曝多半在这一路），再关 `customAdditivePipeline`，
最后关 `sceneMaterials`。关掉后对应粒子退回原版管线或普通画法，效果会减弱，但不会再和光影包互相影响。

自建程序不经过光影包的雾、曝光和色调映射，所以即使开关全开，粒子颜色和包内画面也可能不完全协调。
自己维护光照模型的光影包可以读[动态光源快照](lighting.md#客户端配置与光影)，按自己的预算取光源，
不必依赖模组把光烘进地形。

## 方块表面软化

`soft` 沿世界坐标六轴查询方块碰撞面，并按距离调整整颗粒子的透明度。
`depth_fade` 按每个片段到已写入深度的表面的距离淡出。见[场景材质](particle-commands.md#读取场景的粒子外观)。
